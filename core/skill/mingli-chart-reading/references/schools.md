# 流派分歧与出处可信度

脚本的默认值和 ChroniQ 网页一样，只有八字的「交节对照」默认按实际时刻。每条注明可信度：

- **A 已核实**：读过实现源码，或者找到了原文、可靠的引述；
- **B 通行说法**：命理界广泛流传，但没能核对古籍原文；
- **C 待核实**：出处本身就有分歧，引用时要说明各家说法不一。

括号里是 `--school` 的写法，默认值标 *。完整的选项说明用 `node scripts/chart.mjs schools` 查看。整理自 ChroniQ 的 `docs/schools.md`。

## 八字

| 分歧 | 选项 | 可信度 |
|---|---|---|
| 晚子时日柱：23:00–24:00 出生，日柱算哪一天 | *日柱算当天 `sameDay`；日柱算次日 `nextDay`（键 `bazi.ziHour`） | A，两种都来自 tyme4ts 的实现 |
| 起运算法：都按「三天折一年」，精度和取整不同，起运日期可差几天到几个月 | *精确到分钟 `default`；按天数和时辰差 `sect1`；按分钟数取整 `sect2`；元亨利贞 `china95`（键 `bazi.childLimit`） | A |
| 天乙贵人：只在庚日有分歧 | *庚取丑未 `gengOxGoat`；庚取寅午 `gengTigerHorse`（键 `bazi.tianYi`） | B |
| 阴干羊刃 | *顺排，乙辰丁未己未辛戌癸丑 `forward`；逆排 `backward`；阴干无刃 `yangOnly`（键 `bazi.yangRen`） | 顺排、逆排 C；阴干无刃 B |
| 贵人类神煞查法：天乙、太极、文昌、国印 | *日干加年干 `dayAndYear`；只看日干 `dayOnly`（键 `bazi.stemRef`） | C |
| 三合类神煞查法：驿马、桃花、华盖、将星、劫煞、亡神、灾煞 | *年支加日支 `yearAndDay`；只看年支 `yearOnly`；只看日支 `dayOnly`（键 `bazi.branchRef`） | C |
| 午未合化 | *化土 `土`；化火 `火`（键 `bazi.wuWei`） | C |
| 交节对照：出生离交节只差几小时时，年柱、月柱和起运按哪个时刻和交节比 | *按实际时刻 `instant`，用世界时比，与时区、真太阳时无关；按排盘时间 `local`，把钟表时间或真太阳时直接和北京时间的交节时刻比，这是 ChroniQ 网页的做法（键 `bazi.jie`） | A，节气本是天文时刻 |

没有做成设置、但同样有分歧的地方：

- **魁罡**：取庚辰、庚戌、壬辰、戊戌四日，也有资料加上壬戌。
- **红艳煞、孤鸾煞、十恶大败、阴差阳错**：各家列出的日柱略有出入。
- **真太阳时**：钟表时间换成世界时，再加经度 × 4 分钟和均时差。均时差用近似公式，误差约 ±1 分钟。不用真太阳时（`--clock`）就直接用钟表时间，夏令时也不扣除。
- **旺衰**：脚本的「旺衰」是简化算法，其余七字加权，月支算三份，再加中气、余气的根。各派判断方法不一。
- **喜用神**：扶抑、调候、通关、从格等取法不同，脚本不算，由解读者判断并说明理由。

## 紫微斗数

排盘引擎是 iztro，只能切换 iztro 支持的分歧。出处大多是通行说法，可信度多为 C。

| 分歧 | 选项 |
|---|---|
| 安星法：两派主星位置相同，命主和部分杂曜不同 | *通行版 `default`；中州派 `zhongzhou`，王亭之所传（键 `ziwei.algorithm`） |
| 命盘年份分界 | *正月初一 `normal`；立春 `exact`，与八字一致（键 `ziwei.yearDivide`） |
| 运限年份分界 | *正月初一 `normal`；立春 `exact`（键 `ziwei.horoscopeDivide`） |
| 小限分界 | *按年份 `normal`；按生日 `birthday`（键 `ziwei.ageDivide`） |
| 晚子时 | *算当天 `current`；算次日 `forward`，iztro 的默认（键 `ziwei.dayDivide`） |
| 天马 | *按生年支，即年马 `year`，《紫微斗数全书》「寅午戌人马居申」；按生月，即月马 `month`，见于部分门派（键 `ziwei.tianma`） |
| 庚干四化 | *阳武阴同 `yangWuYinTong`；阳武同阴 `yangWuTongYin`；阳武府同 `yangWuFuTong`（键 `ziwei.mutagenGeng`） |
| 戊干化科 | *右弼 `tanYinBiJi`；太阳 `tanYinYangJi`（键 `ziwei.mutagenWu`） |
| 壬干化科 | *左辅 `liangZiZuoWu`；天府 `liangZiFuWu`（键 `ziwei.mutagenRen`） |

星曜亮度（庙旺得利平不陷）不是设置项，按《紫微斗数全书》的表，可信度 B。格局按《紫微斗数全书》《骨髓赋》的通行定义判断。

## 星盘

采用回归黄道，即以春分点为白羊 0°。位置由 astronomy-engine 计算，误差约 1′。可信度 A。

| 分歧 | 选项 |
|---|---|
| 宫位制 | *普拉西度 `placidus`；整宫制 `whole`；等宫制 `equal`（键 `star.houses`）。普拉西度在极圈内无法定义，会退回等宫制 |
| 月交点 | *真交点 `true`；平交点 `mean`，两者最多差约 1.5°（键 `star.node`，七政四余同名的键也一起改） |
| 推运的上升和天顶 | *太阳弧 `solarArc`；Naibod `naibod`（键 `star.progAngles`） |

- **相位**：只列合、冲、刑、拱、六合五种。容许度为合、冲 8°，刑、拱 7°，六合 5°，涉及日月再加 2°。
- **行运、推运、合盘的容许度**：
  - 行运与本命：2°；
  - 推运与本命：1°；
  - 合盘：比本命小 2°；天王星、海王星、冥王星彼此之间的相位不列。
- **暂未提供**：凯龙星、莉莉丝，次要相位，太阳回归盘、太阳弧盘。

## 七政四余

| 分歧 | 选项 | 可信度 |
|---|---|---|
| 罗睺计都 | *罗睺为升交点（北交）`ascending`，清代《时宪历》以来的通行说法；罗睺为降交点 `descending`（键 `qizheng.rahu`） | 升交点说 B；降交点说 C |
| 月交点 | *真交点 `true`；平交点 `mean`（键 `qizheng.node`） | A |
| 紫炁：天上没有对应的天体 | *二十八年一周天 `cycle28`，起点是 ChroniQ 的约定，不出自古书；不排 `hidden`（键 `qizheng.ziqi`） | C |

- **七政**：取地心视位置，按赤经归入二十八宿，入宿度用古度，周天 365¼ 度。可信度 A。
- **十二次**：从春分点起，按黄道每 30° 一次，这是《时宪历》的分法。命宫取上升点所在的次。《果老星宗》一系按宿度定宫界，脚本没有这个选项。可信度 B。
- **月孛**：取月亮的平远地点。可信度 B。
- **时间**：七政四余用出生那一刻的真实星空，按当地钟表时间换算成世界时，不用真太阳时。
