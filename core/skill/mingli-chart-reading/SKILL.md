# 命理排盘与解读

排盘交给 `scripts/chart.mjs`。它是 chroniq-core（ChroniQ 星曆的计算部分）打成的单个文件，用 node 20 以上直接运行，不联网，也不写任何文件。你只做两件事：把出生信息交给它，再照它排出的盘解读。

## 四条硬规则

1. **绝不自己排盘。** 干支、节气、藏干十神、星曜、四化、宫位、行星度数、大运年份，全都以脚本输出为准，引用时照抄。脚本没算的东西不要凭记忆补上，比如神煞表外的神煞、小限、流年神煞、命主度主。确实要用时，说明「这是按某家古法推的，脚本没有算」。模型自己排盘常出错，节气交接、宫位和度数尤其容易错。
2. **不保存出生信息。** 出生日期、时间、地点和排出的盘，不写进 memory、文件或笔记，也不放进网址、搜索或别的服务。只在命令行里交给本机脚本。用户想以后再用，请他自己保存。举例和测试只用虚构的生日。
3. **不渲染宿命。** 不预言生死、疾病、官司、灾祸。健康和钱财只说倾向，并提醒以现实为准：身体找医生，钱财找专业人士。好的和要留意的都说，语气温和，给能做的建议。命理是传统文化的参考，不是定论。
4. **流派要说清。** 说明盘是按哪个流派排的。输出里的「提示」和「受流派影响的结果」要转告用户，遇到分歧时把两种结果都讲。

## 第一步：问齐出生信息

| 盘 | 日期 | 时间 | 性别 | 出生地 |
|---|---|---|---|---|
| 八字 | 必须 | 最好有，没有就只排三柱 | 必须 | 最好有，用来算真太阳时 |
| 紫微 | 必须 | 必须 | 必须 | 最好有 |
| 星盘 | 必须 | 必须 | 不用 | 必须 |
| 七政四余 | 必须 | 必须 | 必须 | 必须 |
| 黄历 | 那一天 | — | — | — |
| 天象 | 起始日 | — | — | 观测地 |

缺什么，一次问完，每项用半句话说明为什么需要。

- **公历还是农历。** 不确定时要问。长辈报的生日常是农历。农历加 `--lunar`，闰月再加 `--leap`。
- **时间写当地钟表时间。** 海外出生就写当地时间和当地城市，不要自己换成北京时间。夏令时也不用自己扣，脚本会按出生当时的时区规则处理。
- **只知道时辰时**，取时辰中间，例如巳时写 10:00，并告诉用户。子时要问清楚是 23 点到 24 点，还是 0 点到 1 点。
- **用户说不清时间**，先问能不能查到，比如出生证明或家人的记忆。实在没有：
  - 八字用 `--time unknown` 排三柱，并说明时柱、命宫、身宫都排不出来；
  - 紫微和七政四余不排；
  - 星盘只能用 12:00 看行星落在哪个星座，上升、宫位和月亮都不准，要先讲明。
- **没有出生地时**，八字和紫微按北京时间的钟表时间排，不做真太阳时修正。星盘和七政四余要出生地，不能排。
- **出生地不在城市表里**（用 `cities` 查），写成 `"名称,纬度,经度,IANA时区"`，北纬、东经为正，精确到 0.01°。把用的坐标告诉用户，请他核对。

## 第二步：运行脚本

脚本在本 skill 目录下的 `scripts/chart.mjs`。用绝对路径运行，含空格的参数加引号：

```bash
node "<本skill目录>/scripts/chart.mjs" bazi --date 1990-05-17 --time 10:30 --gender 男 --place 北京 --year 2026
```

| 要做的事 | 命令 |
|---|---|
| 八字，加流年和十二个流月 | `bazi --date … --time … --gender … --place … --year 2026`（可写 `2026-2028`） |
| 八字某一天的岁运（大运、流年、流月、流日） | `bazi … --on 2026-11-10` |
| 紫微，加大限和流年 | `ziwei --date … --time … --gender … --place … --year 2026` |
| 紫微某一天（加流月、流日） | `ziwei … --on 2026-11-10` |
| 星盘本命 | `star --date … --time … --place …` |
| 行运 / 推运 | `star … --transit 2026-11-10`（可写 `2026-11-10T08:00`）/ `star … --progress 2026-11-10` |
| 合盘 | `star … --partner-date … --partner-time … --partner-place …` |
| 七政四余 | `qizheng --date … --time … --gender … --place …` |
| 黄历 | `almanac --on 2026-11-10`；加上出生信息，再看这一天对这张八字 |
| 天象 | `sky --on 2026-11-10 --days 30 --place 上海` |
| 流派选项、城市表、全部用法 | `schools`、`cities`、`--help` |

- 换流派用 `--school 系统.键=值`，可以重复写，例如 `--school bazi.ziHour=nextDay`、`--school star.houses=whole`、`--school ziwei.algorithm=中州派`。
- 默认给了出生地，八字和紫微就按真太阳时排。用户要按钟表时间排时，加 `--clock`。
- 星盘一次只能叠一种：行运、推运、合盘，要几种就运行几次。
- 用户问的年份没说明时，取今天所在的年份。注意流年按立春换年：立春前的一月，流年还是上一年。

脚本报「错误：…」并以退出码 2 结束时，说明输入有问题，例如夏令时跳过的时刻、不存在的日期、缺了某一项。把错误原因转告用户，问清楚以后再排。

## 第三步：先看「提示」

输出开头有「排盘依据」「流派」，有时还有「提示」。解读之前，先把提示里影响结论的内容用一两句话告诉用户：

- **交节附近**：出生时间稍有出入，月柱、年柱就可能是另一柱。脚本拿出生的实际时刻和交节比（`bazi.jie=instant`，和 ChroniQ 网页一样）。海外出生、夏令时出生或用真太阳时的，直接查北京时间万年历的比法（`bazi.jie=local`）可能落在交节另一边，提示里会给出那一版的年柱、月柱。
- **真太阳时换了柱**：用不用真太阳时，时柱（偶尔日柱）不同。
- **时辰交界、晚子时**：时柱、日柱，或者紫微的整张盘，可能不同。
- **夏令时**：时间出现过两次时，取的是较早的一次。
- **紫微和八字的年界不同**：紫微按正月初一换年，八字按立春换年。

影响大时，用另一种设置再排一次（例如 `--school bazi.ziHour=nextDay`、`--clock`、`--school bazi.jie=local`），把两种结果的差别讲清楚。每一版都要是脚本完整排出的盘：不要把几次运行的结果拼成一张盘，也不要拿别的日期凑出相同的四柱。脚本排不出你要的那一版时，就照实告诉用户。

## 第四步：照盘解读

每个论断都说出依据：哪一柱、哪个十神、哪颗星在哪一宫、哪个格局或相位。例如「流年丙午，丙火对日主壬水是偏财」。术语第一次出现时用一句话讲明白。用 Markdown 写，小标题分段，要点用短列表。

- **八字。** 先总论日主强弱、格局和喜用神的取法，并说明理由。再分性格、事业、财运、感情、健康几方面。最后看当前大运和流年，给出这几年的建议。
  - 脚本的「旺衰」是简化算法：月令算三份，再加通根。要说明各派判断方法不一，再用月令、通根、透干给出你自己的判断。
  - 喜用神是你的判断，不是脚本算的。要说明用的是扶抑、调候还是通关，以及为什么这样取。
- **紫微。** 先看命宫、身宫和三方四正的主星组合，说性格和格局。盘里列出的格局，逐个说成不成立、强不强。再看财帛、官禄、夫妻、迁移、疾厄几宫。生年四化和宫干飞化里值得注意的说一说。最后看当前大限和流年。
- **星盘本命。** 先说太阳、月亮、上升三要素，以及元素、模式的分布；元素只数太阳到冥王星十颗行星。再看行星的星座和宫位，以及最紧的几个相位。分性格、事业、感情、人际、成长课题几方面。有逆行、某一宫行星集中，或空宫时也说一说。
- **行运、推运。** 看最紧的几个相位和落宫，说这段时间的主题，哪些方面顺、哪些要留意，给几条建议。本命盘简要带过。
- **合盘。** 看对方的行星落在哪些宫，以及主要相位。说两人在哪些方面合得来、哪些地方容易摩擦，给相处的建议。
- **七政四余。**
  - 先看命宫所在的次、命度所在的宿和守命的星。
  - 再看日躔、月离，五星各在哪一宿、哪一次，以及和它本身五行的生克。
  - 然后看四余的落宫，和财帛、官禄、夫妻、迁移、疾厄几宫。
  - 紫炁这类依流派推算的星，只作参考。
- **黄历。** 讲干支和节气的意思。宜忌里挑最值得说的几样，解释为什么宜、为什么忌。再说值神和星宿的寓意，给两三条建议。不用把整份黄历重抄一遍。

## 预测类问题

例如「今年适合换工作吗」「这三年财运怎样」「下个月适合搬家吗」。

1. 用对应年份跑 `bazi --year …`。时间确定的，加跑 `ziwei --year …`。问到具体日子的，用 `--on` 或 `almanac --on … ` 加上出生信息。
2. 看三样，都在「岁运」一段里：
   - **当前大运**：它的十神，以及和原局的刑冲合会。这一年交运的话，要分交运前后说。
   - **流年**：天干、地支藏干对日主是什么十神；是本命年还是冲太岁。
   - **刑冲合害**：流年、大运和原局四柱之间的关系，以及流年和大运之间的关系。
3. 按喜用神判断这些十神和五行是助力还是阻力，再用「流月」挑出比较顺、和要留意的月份。
4. 十神和事情的对应（看事业时常用）：

   | 十神 | 对应的事 |
   |---|---|
   | 正官、七杀 | 职位、上司、规则和压力 |
   | 食神、伤官 | 表达、技术、作品；也指想跳出原有框架 |
   | 正财、偏财 | 收入、机会、经营 |
   | 正印、偏印 | 学习、证书、贵人、单位的庇护 |
   | 比肩、劫财 | 同辈、竞争、合伙、开销 |

   刑冲合害的含义：冲主变动，合主牵绊或合作，刑、害、破主摩擦和是非。
5. 给出倾向，比如「偏向适合，最好在几月前后」或「今年宜稳，先做准备」，说明条件，再加现实的建议，比如先找好下家、看清合同。不说「一定会」「必然」这类断语。

## 流派

默认设置和 ChroniQ 网页一样。八字的「交节对照」网页里没有设置项，固定按实际时刻，因为节气是天文时刻；脚本可以用 `--school bazi.jie=local` 换成直接查北京时间万年历的比法。输出的「流派」一行列出这次用的选择，改过的标「（非默认）」。「受流派影响的结果」一行列出随设置变化的神煞和合化。用户点名某个流派时（如「按中州派」「用整宫制」），用 `--school` 切换，选项用 `schools` 查。

分歧和出处可信度见 [references/schools.md](references/schools.md)：A 已核实，B 通行说法，C 待核实。引用 C 级的规则时，要说明各家说法不一。喜用神的取法、格局的成败，各家也不一样，同样要说明你按的是哪一种。

## 用英文提问时

用英文回答。中文术语保留中文，第一次出现时括号附英文解释，例如「偏财 (Indirect Wealth)」「命宫 (Life Palace)」。常用译名见 [references/glossary-en.md](references/glossary-en.md)。脚本输出是中文，只翻译讲解，不改数据。星盘的行星、星座、相位直接用英文通行名。
