# Moon maps

From NASA's Scientific Visualization Studio, CGI Moon Kit (https://svs.gsfc.nasa.gov/4720),
credit "NASA's Scientific Visualization Studio". Equirectangular, longitude 0 at the centre,
east to the right, north up.

- `lroc_color_2k.jpg`: the 2025 colour map, 2048×1024 (from LRO's LROC WAC)
- `lroc_color_poles_1k.jpg`: the 2019 colour map with the poles, 1024×512
- `ldem_3_8bit.jpg`: heights (LRO's LOLA), 1024×512, 8-bit

The 观月 page (MoonGlobe) wraps them on a sphere, lit by the Sun; only that page loads them.
