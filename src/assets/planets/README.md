# Planet maps

Maps of Mercury, Venus (its clouds), Mars, Jupiter, Saturn, Uranus and Neptune, from
[Solar System Scope](https://www.solarsystemscope.com/textures/) (based on NASA imagery),
under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Scaled down here to 1024 × 512.

The 天象 page wraps them round the planets once zoomed in (`src/components/SkyGlobe.tsx`).
The Moon's maps are in `../moon/`.
