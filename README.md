# 星曆 ChroniQ

中国传统历法与命理排盘工具：万年历、天象、八字排盘、紫微斗数，以及西洋占星星盘。

在线访问：<https://redcarpg.github.io/web-paipan-ChroniQ/>

一个纯前端的中国传统历法应用：

- **日历**：有月、周、年三种视图。周视图列出一周七天的建除和宜忌；年视图一屏显示十二个月，节气、节日、法定假日用颜色标出，每月下方列出当月的节气和节日。月视图里可以用年、月下拉框切换，或者点日历图标展开选择面板（年份网格、月份网格、跳到指定日期）；格子里在农历日期下方显示日干支，周末带浅色底色。月视图显示公历、农历、节气、节日和法定节假日（休/班）。点击任意一天可以查看干支、建除、值神、星宿、宜忌、吉神凶煞。
- **天象**：「此刻天空」画出所选观测地上空此刻（或任选时刻）的太阳、月亮、行星和 1,600 多颗 5 等以内的亮星，天顶在中心、上北左东，如仰望天空，并列出各天体的方位、高度和星等；日月和肉眼可见的五大行星还画出前后 12 小时划过天空的轨迹（虚线已走过、实线将要走，圆点为整点，悬停可看各整点时刻，可用「轨迹」开关）；可用「视角」切到「脚下」，看地平线以下被地球挡住的那半边天空（中心是天底，东西左右互换）；可叠加西方 88 星座或中国星官（三垣二十八宿等）的连线与名称；还可选一个天体，画出它过去 1 个月 / 3 个月 / 1 年在星空中走过的路线（画在此刻的星空上，标出日期，行星逆行时会折返或打圈）；观测地可选城市、自定义经纬度，或用浏览器定位「用我的位置」。「太阳系」从黄道北极俯视各行星在轨道上的位置，可看内太阳系（真实比例）或全太阳系（距离按平方根压缩），列出各行星距太阳、距地球的距离、光行时，以及从地球看是顺行还是逆行；可选日期，或按 1 天 / 1 周 / 1 月 / 1 年每秒播放行星运行，悬停行星可看地球到它的视线。行星位置由 astronomy-engine 计算，星表和西方星座连线来自 d3-celestial（BSD-3-Clause），中国星官来自 Stellarium 的中国星空文化（CC BY-SA 4.0，经 d3-celestial 整理；生成的 `src/lib/xingguan.ts` 按同一许可共享），只在打开天象页时加载。
- **紫微斗数**：与八字共用出生信息、真太阳时和已保存的命盘，以传统 4×4 方盘显示十二宫：主星、辅星、杂曜及其亮度，生年四化，长生十二神，大限年龄；中宫显示五行局、四柱、命主、身主。星曜可按五行或按吉凶着色；悬停或点按宫位会高亮它的三方四正（本宫、对宫、三合宫）并在中宫连线，悬停星曜可看类别、星性、亮度和四化的解释。盘上方可切到「四化飞星」：悬停或点按宫位，用箭头标出这一宫的宫干把禄、权、科、忌飞入哪一宫（化忌另注所冲之宫），各宫的宫干自化以「↑禄」等标出；庚、戊、壬三干的飞化跟随流派设置。盘下方的「运限」可选大限、流年、流月、流日、流时，并把对应的宫名（大命、年财、月兄、日福、时官……）、运限四化和流耀（运禄、流羊、月马、日禄、时魁……）按层叠加到盘上，每层一种颜色，新叠加或取消的一层淡入淡出；「本命」一键回到原盘。默认只展开大限一行，选中一级后自动展开下一级；再点一次已选中的一级即退回上一层，更细的各行随之收起。紫微有自己的流派设置，可选安星法、年份分界、小限分界、晚子时、天马（年马或月马）和庚戊壬三干的四化。排盘引擎为 [iztro](https://github.com/SylarLong/iztro)（MIT），只在打开紫微页时才加载。
- **星盘**（西洋占星本命盘）：与八字共用出生时间和出生地：中国城市、约 70 个海外主要城市，或自定义经纬度与时区。显示太阳、月亮、上升「三巨头」，传统圆形星盘（星座环、宫位、行星与相位线），行星位置、宫位和主要相位表，悬停可看行星、星座、宫位和相位的解释。可切换「行运」「推运」：选定日期时间后，把当时的行星（或二次推运位置）画在外圈，列出落入的本命宫位和与本命的相位。「合盘」比较两个人：对方可从已保存的命盘里选（带上其真太阳时城市作出生地），也可手动输入出生日期、时间和出生地；对方的星体画在外圈，列出它们落在你的哪一宫、你的星体落在对方的哪一宫，以及双方之间的相位和和谐 / 紧张相位的数量（容许度比本命小 2°，天王、海王、冥王彼此的世代相位不列）。「组合盘」用同一位对方，把两张盘合成一张代表关系本身的盘，有自己的星盘图、行星位置和相位；做法可在流派设置中选中点组合盘（Composite）或时空中点盘（Davison）。宫位制（普拉西度、整宫、等宫）、月交点（真、平）、推运天顶（太阳弧、Naibod）与组合盘做法（中点、Davison）可在流派设置中切换；按出生地时区换算世界时，自动计入各地当年的夏令时（含中国 1986–1991 年）。星体位置由 [astronomy-engine](https://github.com/cosinekitty/astronomy)（MIT）计算，只在打开星盘页时加载。
- **八字排盘**：输入出生时间和性别后，显示四柱（主星、藏干、纳音、星运、自坐、空亡）、五行统计、胎元/胎息/命宫/身宫、起运时间、十步大运，以及每步大运内的流年、按节令划分的流月和每天的流日。这些在「岁运」面板里挑选：面板叠在「岁运盘」上，点左侧的「岁运」竖条打开，点「收起」合上后可看完整的岁运盘；大运、流年、流月、流日各行都可以收起或展开。选中的岁运会和原局四柱一起列在「岁运盘」里，八柱并排显示主星、藏干、纳音、星运、空亡和按原局查的神煞，并列出岁运与原局的刑冲合会。再点一次已选中的流年、流月或流日即可取消选中，这一柱就不再列入岁运盘（大运始终列入）；取消流年会一并收起并取消流月、流日，取消流月会一并收起并取消流日，重新选中时下一级自动展开以便接着选。支持两种晚子时日柱流派。
  - **神煞**：天乙、太极、文昌、国印、天德/月德（及合）、禄神、羊刃、红艳、金舆、天医、将星、驿马、桃花、华盖、劫煞、亡神、灾煞、孤辰寡宿、红鸾天喜、丧门吊客、魁罡、阴差阳错、十恶大败、孤鸾、十灵、金神、天赦。
  - **术语说明**：表格的行名（主星、藏干、纳音、星运、自坐、空亡、神煞……）、岁运列名和胎元、命宫等都可以悬停查看解释；纳音会说明它的意象，星运和自坐说明对应的十二长生阶段，空亡说明来自哪一旬。说明文字在 `src/lib/glossary.ts`。
  - **悬停高亮**：鼠标移到某个天干或地支上，和它有刑冲合会关系的柱子以及对应的关系说明一起高亮，其余内容变淡；移到某条关系上会反过来点亮相关的柱子；移到某个十神上，同名十神全部高亮。触屏上点一下即可，键盘可以用 Tab 切换。
  - **命盘保存**：自动记住上次输入。已保存的命盘收在屏幕左侧的「命盘」抽屉里：点开后可命名保存当前命盘、切换或删除，选中后抽屉自动收起；抽屉浮在页面上，不影响排版。命盘只存在本机浏览器里。
  - **分享链接**：八字、紫微、星盘页右上角的分享按钮会生成一个链接（手机上直接调出系统分享），别人打开就是同一张命盘、同一页；星盘页的链接还带上出生地。出生信息只放在链接的 `#` 之后，不会发送到服务器；打开后的出生地不会覆盖对方自己保存的设置。
  - **导出与打印**：八字、紫微、星盘页右上角的导出按钮可「保存为图片」（把八字原局、紫微命盘或星盘本命这张卡片存成 PNG，去掉按钮等控件，右下角注明「星曆 ChroniQ」），或「打印」（只打印命盘内容，不含导航、表单和按钮；深色模式下也按浅色打印）。
  - **刑冲合会**：天干五合/相冲；地支六合、三合、半合、三会、六冲、相刑、自刑、六害、相破。会显示原局内部的关系，也会显示所选大运、流年与原局之间的作用。
  - **流派设置**：晚子时、起运算法、天乙贵人、阴干羊刃、神煞查法、午未合化都可以切换。受流派影响的结果会标一个「!」，说明和出处见 [docs/schools.md](docs/schools.md)。
  - **出生地与真太阳时**：出生地在八字、紫微、星盘三页共用，并随命盘一起保存和分享：可选中国城市、约 70 个海外主要城市，或自定义经纬度与时区。勾选「真太阳时」后，按出生地时区（含中国 1986–1991 年及海外的夏令时）换算世界时，再加经度差与均时差修正出生时间；海外出生同样适用。

- **页面导航与动画**：八字、紫微、星盘页的左侧「命盘」标签下有一列区块导航（如八字的原局 / 岁运），当前所在区块会随滚动高亮，上下两端的 ↑ / ↓ 回到顶端或到达底端。首次打开和首次进入紫微、星盘、天象时显示「星曆」加载画面（至少约 0.9 秒，淡入淡出）；切换页面时左右滑动淡入，星盘切换本命 / 行运 / 推运时各卡片平滑过渡。系统开启「减少动态效果」时这些动画都会关闭。
- **页面菜单**（右上角）：点当前页名打开菜单，按「历法」（日历、天象）和「命理」（八字、紫微、星盘）分组列出各页及其内容，可用方向键选择。
- **安装与离线**：可以安装成应用（Android / 电脑版 Chrome、Edge 在 About 里点「安装到桌面 / 主屏幕」，或从地址栏安装；iPhone / iPad 在 Safari 里点「分享」→「添加到主屏幕」），从桌面或主屏幕像应用一样全屏打开。所有计算都在本机完成：打开过一次后，全部页面（含紫微、星盘、天象）都已缓存，没有网络也能照常使用，离线时页脚会提示。有网络时总是加载最新版本。
- **其他地区节日**：在日历页标题下方的「其他地区节日」里选「法国」，日历会同时显示法国的节假日和重要日期：11 个法定假日（格子左上角标「FR」），阿尔萨斯-摩泽尔额外的两个假日（淡色「FR」），以及主显节、圣烛节、狂欢节、复活节、圣灵降临节、母亲节、父亲节、音乐节和夏令时 / 冬令时切换等日子；点开某天可看法语原名和说明。复活节相关的日期按公历复活节算法推出。其他国家可按 `src/lib/regionHolidays.ts` 里的规则表添加。
- **设置**（右上角齿轮）：界面语言（中文 / English）、颜色模式（跟随系统 / 浅色 / 深色）、专有名词字形（繁體 / 简体，默认繁體）、每周起始（周一 / 周日）、日历格子是否显示日干支、紫微星曜配色、显示大小（自动 / 标准 / 大 / 特大；「自动」在 1500px 以上的大屏幕上按比例放大整个页面）。设置保存在浏览器本地。
- **页脚角标**：右下角「by RedCarpG」链接到作者主页，「About」打开简介面板，内有功能概览、GitHub 源代码、流派说明和反馈链接。

## 英文界面

设置里可以把界面切换成英文。按钮、标题、说明、日期和城市名等界面文字换成英文；干支、十神、神煞、节气、宜忌、紫微星曜和宫名等专有名词仍以中文显示（字形跟随「专有名词」设置），西洋占星的行星、星座、宫位和相位用通行的英文名。悬停时弹出的术语解释目前仍是中文。

界面文字在源码里用中文写，并用 `t('…')` 包起来；英文翻译放在 `src/i18n/en/` 下按页面分开的词典里，以中文原文为键。带数字或名称的句子用占位符，如 `t('{n} 颗亮星', { n })`。`npm test` 会检查每个 `t('…')` 都有英文、占位符一致，同一个键在不同词典里的译法相同。

## 繁體专有名词

干支、神煞、十神、节气、宜忌等专有名词默认以繁體显示，说明文字保持简体。转换用的是一份按字对照的表 `src/lib/tradChars.ts`，由 [OpenCC](https://github.com/nk2028/opencc-js) 在开发时生成，网页运行时不加载 OpenCC。命理用字和 OpenCC 默认结果不同的地方（如「沖」不作「衝」，地支「丑」不作「醜」，「天干」不作「天幹」），在 `src/lib/tradOverrides.ts` 中单独指定。

界面里新增专有名词时，用 `term('…')` 包起来（切换到英文界面时，经过 `term()` 的专有名词仍保持中文），然后运行 `npm run gen:trad` 重新生成对照表；`npm test` 会检查每个名词的转换结果是否和 OpenCC 一致。

## 技术栈

- [Vite](https://vite.dev) + [React 19](https://react.dev) + TypeScript
- 历法和命理计算：[tyme4ts](https://github.com/6tail/tyme4ts)（MIT）
- 紫微斗数排盘：[iztro](https://github.com/SylarLong/iztro)（MIT）
- 星盘星体位置：[astronomy-engine](https://github.com/cosinekitty/astronomy)（MIT）

## 开发

```bash
npm install
npm run dev       # 本地开发
npm run build     # 类型检查并构建到 dist/
npm run preview   # 预览构建结果
npm test          # 单元测试（vitest）
npm run gen:trad  # 重新生成繁體对照表（约 1 分钟）
```

`dist/` 是纯静态文件。推送到 `main` 后，`.github/workflows/pages.yml` 会自动测试、构建并部署到 GitHub Pages；PR 只跑测试和构建，不部署。
